OpenClaw Google Integration

This site describes the Google OAuth configuration used for a personal, self-hosted OpenClaw assistant running on local hardware.

Purpose

The application connects a local OpenClaw environment to Google APIs so the owner can read Gmail, read Google Calendar events, and create Gmail drafts for personal productivity workflows.

How it is used

  • Personal self-hosted assistant use only
  • Runs locally rather than as a public web application
  • Used to access the owner’s own Google account data
